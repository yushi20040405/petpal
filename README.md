# 新标签页萌宠伴侣（Chrome 扩展）

每次打开新标签页，都会有一只可爱的小宠物陪伴你。内置 **20 只小动物**，你可以在弹窗中自由勾选想让哪些小动物出现，每次打开页面会从已勾选的小动物里随机挑一只。

## 功能一览

- 🐾 新标签页接管（`chrome_url_overrides`）+ 全网页悬浮宠物（`content_scripts`）
- 🎬 内联 SVG + 分层 CSS 动画：呼吸浮动、眨眼、点击弹跳、心情/主动小动作
- 🎛️ 点击宠物本体，在宠物周围弹出**环形功能菜单**（喂食 / 喂水 / 玩耍 / 清洁 / 治疗 / 休息）
- 📊 点击宠物同时弹出**状态面板**（饱腹 / 口渴 / 精力 / 心情 / 亲密度 / 健康），不再固定显示在下方
- 🍜 点击“喂食 / 喂水”弹出横向滑动的食物 / 饮品列表，投喂后饱腹度 / 口渴度增加，吃饱会拒绝
- 💖 抚摸宠物（不同部位有不同反应）与玩耍时飘出**插画粒子**（蝴蝶结 / 棒棒糖 / 花花），替换原 emoji 爱心
- 😿 新增**健康度**：长期疏于照料会“生病”，可用“治疗”恢复
- 🎲 从已勾选的小动物中随机挑一只展示，并记住当前这只（刷新不换，改选择才重抽）
- 💾 使用 `chrome.storage.local` 持久化全部状态；切换宠物时三态各自记忆，互不影响

## 测试方法

1. 打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择本目录。
2. 打开一个新标签页：点击宠物本体，会在宠物周围弹出环形菜单、在宠物右侧弹出状态面板；再次点击宠物或点击空白处关闭。
3. 依次点击环形菜单各图标：喂食 / 喂水会弹出食物列表（横向滑动、点击投喂）；玩耍 / 清洁 / 治疗 / 休息会触发对应动画与数值变化，可在状态面板查看。
4. 在任意网页右下角会看到悬浮宠物：同样点击宠物弹出环形菜单 + 状态面板（尺寸缩小，靠近屏幕边缘会自动调整到可见范围内）；可拖动、收起。

## 内置小动物（20 只）

小猫、小狗、田园犬、小兔子、仓鼠、松鼠、小猪、小象、老虎、狐狸、小鸡、企鹅、树袋熊、小浣熊、小熊猫、白熊、刺猬、树懒、水獭、娃娃鱼。

## 安装步骤

1. 打开 Chrome，地址栏输入 `chrome://extensions` 并回车。
2. 打开右上角的 **「开发者模式」** 开关。
3. 点击左上角 **「加载已解压的扩展程序」**。
4. 选择本目录（`petpal`，即包含 `manifest.json` 的那个文件夹）。
5. 打开一个新标签页即可看到宠物；点击工具栏上的扩展图标可勾选小动物。

> 若图标尚未生成，先在目录下运行 `node generate-icons.js` 生成 PNG 图标（需要已安装 Node.js）。

## 文件结构

```
petpal/
├── manifest.json         # 扩展清单（Manifest V3）
├── newtab.html           # 新标签页结构
├── newtab.css            # 新标签页样式与动画
├── newtab.js             # 内联 SVG 注入、互动与随机选取逻辑
├── popup.html            # 弹窗结构（勾选小动物）
├── popup.css             # 弹窗样式
├── popup.js              # 弹窗逻辑（多选与持久化）
├── pets.js               # 全部 20 只小动物的资源清单（共享）
├── assets/               # 小动物插画 SVG
├── generate-icons.js     # 图标生成脚本（一次性）
└── icons/                # 生成的 PNG 图标
```

## 数据存储说明

`chrome.storage.local` 中保存：

| 键 | 含义 | 默认值 |
| --- | --- | --- |
| `selectedPets` | 被勾选的小动物 id 数组 | 全部 20 只的 id |
| `currentPet` | 当前展示的小动物 id（避免刷新后变化） | `null`（首次随机） |
